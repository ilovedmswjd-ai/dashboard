국방예산 프로그램별 재원 대시보드

실행: index.html을 브라우저에서 열면 됩니다. 설치나 인터넷 연결이 필요 없습니다.

구성
- 부문·회계구분 필터: 요약 지표, 차트 8개, 상세표에 동시 적용
- 부문 변경 시 해당 부문에서 가능한 회계구분만 표시
- 상세표: 프로그램 검색, 열별 정렬, 현재 표시 결과 CSV 다운로드
- 금액: 억 원. 증감 = 2027년 - 2026년. 증감률 = 증감 / 2026년
- 구성·비중·순위·산점도는 양수 재원 기준, 음수는 차감 재원 차트에 표시
- 그래프 막대·도넛·산점도 위에 마우스를 올리면 상세 수치 확인
- 스마트폰과 태블릿 화면에 맞춰 배치 조정

원본: 상위 폴더의 붙임1_프로그램별_재원.xlsx
data.js는 제작 당시 엑셀에서 추출한 32개 행의 데이터입니다.
엑셀 변경 내용은 자동 반영되지 않습니다.

파일: index.html / styles.css / app.js / data.js
